NeoUtlのお部屋

NeoUtlとは…

AviUtl ExEdit ライクな動画編集ソフトウェアです。Linux や Windows で動作します。macOS も将来的にサポートする予定です。現在はプレアルファです。

★ インフォメーション ★

新しい GUI クレートを開発しています

NeoUtl はこれまで、様々な GUI を採用し、検証してきました。 しかし、どの GUI も NeoUtl のニーズを満たすことは難しかったので、NeoUtl の開発を休む傍ら、新しい GUI クレート「contixion」を開発することにしました。 仕様や実装の基盤は既に堅牢に固められつつあり、開発を再開する際に、NeoUtl の GUI 実装を contixion に移植する予定です。 現在 contixion は非公開です。

Madoka Launcher をリリースしました

Madoka Launcher は、NeoUtl だけでなく、AviUtl（ExEdit 0 / 2）、YMM4 、Freya-NLE 等のバージョン、複数インスタンス、プラグインを一箇所で管理できる便利なツールです。 AviUtl２カタログ等の既存のリポジトリを参照するため、常に最新のプラグインを簡単にダウンロードすることが可能です。

大学受験の為に NeoUtl の開発を休止しています

2027 年度に開発を再開する予定です。

Zulip コミュニティを開設しました

NeoUtl について気軽に話せるコミュニティです。
開発状況の確認、質問、バグ報告、機能への提案などを、 NeoUtl の開発者やユーザーと交流しながら行えます。 こちらから参加することができます。
ブラウザからのご参加は勿論、デスクトップ・モバイル向けの Zulip アプリもご利用頂けます。

★ ビルド手順 ★

NeoUtl
最新のNeoUtl（mainブランチ）はRustで実装されています。ビルドを行うには、予め Rust、Clang、Mold、FFmpeg をシステムにインストールしてください。
ソースコードの取得とビルド
git clone "https://codeberg.org/TeamNeoUtl/NeoUtl.git"
cd NeoUtl
git switch main
cargo xtask build --release
実行可能ファイルは target/release 以下に生成されます。

AviQtl
NeoUtlの源流となる旧プロジェクトです。ビルドには Python3 及び PySide6 環境が必要です。
ソースコードの取得とビルド
git clone "https://codeberg.org/TeamNeoUtl/NeoUtl.git"
cd NeoUtl
git switch aviqtl
python3 BUILD.py
実行可能ファイルは build 以下に生成されます。
